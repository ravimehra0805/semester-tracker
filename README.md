# Semester Tracker

A simple web app for college students to track assignments, labs and deadlines in one place.
Built with plain HTML, CSS and JavaScript (no frameworks), so it runs by just opening `index.html`.

## Features
- Add tasks with subject, due date and priority (High / Medium / Low)
- Mark tasks done, delete tasks, filter by All / Pending / Done
- Overdue tasks are highlighted; tasks are sorted by due date
- Progress bar showing how much is completed
- Data is saved in the browser using `localStorage`
- Responsive layout, dark mode support, keyboard accessible

## Tech Stack
HTML5, CSS3 (Grid, Flexbox, CSS variables), JavaScript (ES6, DOM, localStorage)

## Run locally
1. Download or clone this repo
2. Open `index.html` in any browser
